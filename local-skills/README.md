## Article workflow reminder

When adding an article to `/Users/peter/Desktop/code/articles/`:

1. Check `README.md`, `MOC.md`, and recent date folders for duplicate coverage.
2. Create both Chinese and English article files under the top-level date folder.
3. Preserve meaningful source images locally under `YYYY-MM-DD/imgs/<slug>/`.
4. Embed local image links in both language versions.
5. Update `README.md` and `MOC.md`.
6. Verify bilingual pairs, image paths, and index links.
7. Commit and push by default.
8. Return verified GitHub links for both article versions.

For WeChat sources, use the copied `articles-repo-maintenance/references/wechat-source-articles.md` workflow.
