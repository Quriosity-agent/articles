- **LibTV 是第一个同时面向人类和 Agent 的 AI 视频创作产品**，官网 https://www.liblib.tv/
- 人类用**无限画布**（节点式界面），Agent 用 **Skills**（一句话调用后端能力）

## 一、产品概述：LibTV 是什么

LibTV 是 liblib.art 推出的 AI 视频创作平台。它的核心卖点不是"又一个 AI 视频工具"，而是**双入口设计**：

1. **面向专业用户**：节点式无限画布，支持剧本→图片→视频→音频全链路
2. **面向普通用户/Agent**：通过 Skills 一句话调用，后端 Agent 自动处理分镜、选模型、调参数

两个入口共享同一套底层原子化能力。

## 二、面向人类：无限画布的能力拆解

### 图片处理（"变态级"）

| 能力 | 说明 |
|------|------|
| 基础处理 | 高清、扩图、重绘、擦除、抠图 |
| 多角度生成 | 预设多视角，一张图生成任意角度，带 3D 预览 |
| 灯光控制 | 一键改光照角度/亮度，支持轮廓光，极其稳定 |
| 反推 Prompt | 引用图片反推文本描述 |
| 图生图/图生视频 | 无缝衔接下游任务 |

### 摄像机控制

这是文章中最让作者惊叹的功能——**真正的摄像机参数 UI**：

- 相机实体模型选择（如 Canon K-35）
- 镜头实体参数
- 光圈和焦距控制
- 预设风格、尺寸、比例、模型选择

### 视频生成

- 支持"几乎所有"视频模型（缺 Seedance 2.0，因为没有对外开放 API）
- 生成后可继续剪辑、超分
- **解析功能**：对视频进行细节拉片分析

### 脚本与分镜

- 剧本节点：输入剧本 → 自动生成分镜脚本
- 角色设定 + 描述 → 生成分镜
- 对 AI 短剧、AI 漫剧场景非常实用

### 其他

- 音频节点：音频驱动数字人、生成音乐
- 斜杠命令（`/`）：隐藏更多功能和预设
- 积分和会员与 liblib 打通，零成本迁移

## 三、面向 Agent：Skills 架构设计

这是本文**最值得 Builder 关注的部分**。

### 安装方式

```
帮我安装 https://github.com/libtv-labs/libtv-skills 这个 skill
```

支持 Claude Code、Codex、OpenClaw 等主流 Agent 平台。安装后设置 Access Key 即可使用。

### 架构设计（核心洞察）

LibTV 的 Skills 采用了一个**非常聪明的架构**：

```
用户 Prompt → Agent（Claude Code 等）→ LibTV Skills（触发+通信）→ LibTV 后端 Agent → 模型调用 → 返回结果
```

**关键决策：用户侧 Skills 只负责触发和通信，真正的能力全跑在后端 Agent 上。**

这意味着：
- 后端可以不断迭代 Prompt、模型策略、分镜逻辑，外部看不到
- 核心 Know-how 不会因为开源 Skills 而泄露
- 对外发布的是**接口，不是大脑**

### 为什么这个架构值得学习

> Agent 生态需要开放，但开放不等于把自己的核心竞争力全部掏出来送给别人。

很多 Skills 开发者把所有逻辑直接放在 SKILL.md 或脚本里，等于裸奔。LibTV 的做法是：

- **开放层**：轻量 Skills，只做触发和通信
- **保护层**：核心模型调用、分镜生成、参数优化全在后端
- **商业化空间**：有壁垒才有保护，有保护才有商业化

### 使用示例

**生图：**
```
帮我生成图片：黑白、模糊的歌剧芭蕾舞者，使用 Canon K-35 拍摄，
风格为 Jeanloup Sieff，16:9，2K，帮我生成 4 张。
```

Agent 自动调用 LibTV Skills → 后端处理 → 几十秒返回 4 张图 + 自动下载本地 + 画布项目链接。

**生视频：**
选择生成的图片，告诉 Agent "用这张图生成 10 秒视频"→ 约 2 分钟返回。

**进阶玩法：**
- 一句话复刻爆款视频 → 生成 TVC 广告
- 一句话给歌曲配 MV（例：根据坂本龙一《Rain》做 MV）

### 画布联动

每个 Agent 任务会**自动创建画布项目**，节点串联好。可以：
- 在画布上继续手动优化
- 与真实项目联动

这就形成了完整的工作流：**Agent 出初稿 70 分 → 人类在画布上优化到 100 分**。

## 四、Builder 核心收获

### 1. 产品设计：双入口模式

同一个产品、同一套底层能力，通过两个完全不同的入口，分别服务两类用户：

- **专业用户** → 无限画布（复杂度 = 武器）
- **普通用户** → Agent Skills（言出法随）

这不是"简版/专业版"的老套路，而是**根本性的交互范式差异**。

### 2. Skills 架构：接口不是大脑

对 Skills 开发者的启示：
- 用户侧 Skills 只做触发和通信，保持轻量
- 核心逻辑放后端，保护 Know-how
- 这样才有迭代空间和商业化可能

### 3. Agent + 人类协作模式

> Agent 出初稿，人类优化——这可能是未来最普遍的创作方式。

LibTV 把这个理念做成了产品闭环：Agent 生成 → 自动创建画布项目 → 人类在画布上精修。

### 4. 缺什么

- 缺 Seedance 2.0 支持（API 未开放）
- Agent 体验还在早期，入口不够显眼
- Skills 用户侧暴露的功能还比较少

## 五、总结

LibTV 可能是第一个真正想清楚"Agent 时代产品该怎么设计"的 AI 视频工具。

核心判断：**底层能力原子化 + 双入口（人类画布 / Agent Skills）= Agent 时代的产品形态**。

对 Builder 来说，最值得借鉴的不是功能列表，而是这个架构思路：
- 你的产品能不能同时服务人类和 Agent？
- 你的 Skills 是在"送大脑"还是"送接口"？
- 你的 Agent 协作是不是形成了闭环？

这些问题，LibTV 给出了一个不错的参考答案。
