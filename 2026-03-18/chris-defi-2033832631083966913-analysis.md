## TL;DR

匿名博士（@Chris_Defi）在做自媒体视频一键工作流的过程中，把 GitHub 上所有视频生成相关的开源项目过了一遍，整理出一份覆盖 **7 大类、35+ 项目** 的全景图。这不是一般的收藏贴——它是按**实际生产需求**分类的，从本地部署的视频生成模型、到浏览器端编辑器、到全自动短视频 Pipeline，再到数字人口型同步和 AI 短剧生成，几乎覆盖了 2026 年 AI 视频领域所有开源能力。

**为什么这篇值得认真看？** 因为它是 Builder 视角的选型参考，不是"awesome-list"式的堆砌。

## 七大类目详解

### 🤖 一、AI 视频生成模型（本地部署）

这一类是基础能力层。关键变化：2026 年你不再需要 API，本地一张 4090 就能跑。

| 项目 | 亮点 | 实用建议 |
|------|------|----------|
| **HunyuanVideo 1.5** | 腾讯出品，8.3B 参数，当前最强 | 追求极致画质首选 |
| **Wan2.1（万象）** | 阿里力作，中文场景最友好 | 做中文内容的不二选择 |
| **CogVideoX** | 清华 5B，支持 LoRA 微调 | ComfyUI 生态最完整，适合定制化 |
| **LTX-Video** | Lightricks 出品，接近实时 | 16GB 显存福音，要速度选它 |
| **Open-Sora 2.0** | 11B，自带完整训练 Pipeline | 适合做研究和自训练 |
| **Mochi 1** | Apache 2.0 完全开源 | 商用无限制，物理运动感最佳 |
| **Stable Video Diffusion** | 图生视频鼻祖 | 社区插件最丰富 |

**Builder 建议：** 如果你要做产品级集成，优先看 HunyuanVideo 和 LTX-Video——一个质量顶天，一个速度极快。LoRA 微调需求走 CogVideoX。

### ✂️ 二、在线视频编辑器（浏览器端）

这一类是"不装软件就能剪"的方案。2026 年浏览器端编辑器已经成熟到可以做产品了。

| 项目 | 亮点 | 定位 |
|------|------|------|
| **OpenCut** | React + WebCodecs，隐私优先 | 最成熟的 CapCut 开源替代 |
| **OpenReel Video** | 堪比达芬奇，AI 字幕 + 专业调色 | 功能最全 |
| **OpenVideo** | React + PixiJS | CapCut/Canva 克隆版 |
| **Twick SDK** | React 组件库 | 最适合嵌入自家产品 |
| **Omniclip 2.0** | 最轻量 | 适合二次开发 |
| **Vue Video Editor** | Vue 3 技术栈 | Vue 生态首选 |

**Builder 建议：** 做独立产品选 OpenCut；嵌入到自己 SaaS 里选 Twick SDK；Vue 技术栈选 Vue Video Editor。桌面端老牌还有 Kdenlive、Shotcut、OpenShot 可选。

### 🚀 三、短视频自动化 Pipeline

这是最有"钱味"的一类——输入文本，输出成片。

| 项目 | 亮点 |
|------|------|
| **MoneyPrinterTurbo** | 中文生态首选，全自动配音字幕素材 |
| **CineOverview** | AI 插画 + TTS，竖屏 Video Essay |
| **Bilive** | B 站专属，自动录制切片 + 弹幕渲染 + 自动投稿 |
| **AutoClipper** | YouTube/Twitch 高光检测 + Whisper 字幕 |
| **ViMax** | 港大出品，LLM 驱动导演编剧制片一体化 |

**Builder 建议：** 做中文短视频批量生产，MoneyPrinterTurbo 一键起步；做英文 Video Essay 看 CineOverview；做直播切片看 Bilive 和 AutoClipper。ViMax 的 Agentic 架构最有前景，值得关注。

### 🔍 四、视频分析·高光检测

AI 帮你从长视频里找到精彩片段。

- **Lighthouse** — LINE 出品，支持文本查询找高光（学术最前沿）
- **HL-CLIP** — 基于 CLIP 的零样本检测，不需要标注数据
- **UVCOM** — 时刻检索 + 高光检测的 SOTA 统一框架
- **VideoCutterAI** — 最易部署的轻量 Web 工具
- **pyannote-video** — 人脸追踪 + 说话人识别

### ⚙️ 五、视频基础处理工具

Pipeline 的底层基石：

- **FFmpeg** — 万物基础，不解释
- **Remotion** — 用 React 写视频，程序化生成首选
- **MoviePy** — Python 视频编辑库
- **Whisper / faster-whisper** — 语音识别，中文极准
- **AutoFlip** — Google 出品，智能横屏转竖屏
- **react-timeline-editor** — 时间线 UI 组件

### 🎭 六、数字人·口型同步

让照片开口说话：

- **MuseTalk** — 腾讯音乐出品，实时口型同步，本地离线质量最高
- **SadTalker** — 单张照片 + 音频生成说话视频
- **Wav2Lip** — 经典口型同步，社区生态丰富

### 🎬 七、AI 短剧·漫剧生成

流水线批量生产内容：

- **BigBanana AI Director** — 工业级最强，精准控制角色一致性
- **Toonflow** — 小说到视频全流程
- **LocalMiniDrama** — 完全本地部署，隐私优先
- **ai_story** — 视频/动漫/短剧/漫剧四合一
- **story-flicks** — 最轻量一键生成
- **ai-shotlive** — 全流程短剧生成器
- **Komiko** — AI 漫画/韩漫/日漫生成

## 为什么这篇值得关注

1. **完整度极高** — 覆盖了视频生产全链路，从生成到编辑到分发，总计 100K+ GitHub Stars
2. **Builder 视角** — 不是学术论文堆砌，而是按实际使用场景分类，直接告诉你"哪个好用"
3. **时效性强** — 包含 2026 年最新的模型和工具，OpenCut、ViMax、BigBanana 等都是近期项目
4. **商用可行** — 所有项目均免费且可商用，Apache 2.0 / MIT 为主

回复里匿名博士还分享了一个长期维护的文档站：[doc-openvideo.vercel.app](https://doc-openvideo.vercel.app/)，会持续更新这份全景图。

## 我的看法

作为一个在做 AI 视频编辑器（QCut）的 Builder，这份列表几乎覆盖了我日常关注的所有项目。几个值得特别关注的趋势：

- **本地部署成为主流** — 不再依赖 API，一张 4090 就是你的渲染农场
- **Agentic Pipeline 是方向** — ViMax 这种 LLM 驱动的导演-编剧-制片流程会越来越多
- **浏览器端编辑器成熟了** — OpenCut、Twick 这些项目说明 WebCodecs 生态已经可以做产品级应用

如果你在做视频相关的产品或工具，这份列表是必收的参考。
