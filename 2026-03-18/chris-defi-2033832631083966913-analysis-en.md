## The Seven Categories

### 🤖 1. AI Video Generation Models (Local Deployment)

The foundational capability layer. Key shift in 2026: you no longer need APIs — a single RTX 4090 runs these locally.

| Project | Highlights | Use Case |
|---------|-----------|----------|
| **HunyuanVideo 1.5** | Tencent, 8.3B params, current SOTA | Best visual quality |
| **Wan2.1** | Alibaba, best Chinese language support | Chinese content creation |
| **CogVideoX** | Tsinghua, 5B params, LoRA fine-tuning | Most complete ComfyUI ecosystem |
| **LTX-Video** | Lightricks, near real-time generation | Speed priority, 16GB VRAM friendly |
| **Open-Sora 2.0** | 11B params, full training pipeline included | Research & custom training |
| **Mochi 1** | Apache 2.0, fully open | Commercial use, best physics |
| **Stable Video Diffusion** | Image-to-video pioneer | Richest community plugins |

**Builder take:** For product integration, focus on HunyuanVideo (quality ceiling) and LTX-Video (speed). For LoRA customization, CogVideoX.

### ✂️ 2. Browser-Based Video Editors

No installation, runs in the browser. In 2026, browser editors are production-ready.

| Project | Highlights | Position |
|---------|-----------|----------|
| **OpenCut** | React + WebCodecs, privacy-first | Most mature CapCut alternative |
| **OpenReel Video** | DaVinci-level features, AI subtitles + color grading | Most feature-complete |
| **OpenVideo** | React + PixiJS | CapCut/Canva clone |
| **Twick SDK** | React component library | Best for embedding in your product |
| **Omniclip 2.0** | Lightest weight | Best for forking/customization |
| **Vue Video Editor** | Vue 3 stack | Vue ecosystem pick |

**Builder take:** Standalone product → OpenCut. Embed in your SaaS → Twick SDK. Vue stack → Vue Video Editor.

### 🚀 3. Short Video Automation Pipelines

Text in, finished video out. The most commercially viable category.

| Project | Highlights |
|---------|-----------|
| **MoneyPrinterTurbo** | Chinese ecosystem leader, fully automated voiceover + subtitles + footage |
| **CineOverview** | AI illustrations + TTS, vertical Video Essays |
| **Bilive** | Bilibili-specific: auto-record, clip, danmaku render, auto-upload |
| **AutoClipper** | YouTube/Twitch highlight detection + Whisper subtitles |
| **ViMax** | HKU, LLM-driven director-writer-producer agentic workflow |

**Builder take:** Chinese short-video mass production → MoneyPrinterTurbo. English Video Essays → CineOverview. Livestream clipping → Bilive/AutoClipper. ViMax's agentic architecture is the most forward-looking.

### 🔍 4. Video Analysis & Highlight Detection

AI finds the best moments in long videos.

- **Lighthouse** — LINE, text-query highlight search (academic frontier)
- **HL-CLIP** — CLIP-based zero-shot detection, no labeled data needed
- **UVCOM** — SOTA unified framework for moment retrieval + highlight detection
- **VideoCutterAI** — Easiest to deploy, lightweight web tool
- **pyannote-video** — Face tracking + speaker identification

### ⚙️ 5. Video Processing Fundamentals

The building blocks every pipeline needs:

- **FFmpeg** — The foundation of everything
- **Remotion** — Write videos in React, best for programmatic generation
- **MoviePy** — Python video editing library
- **Whisper / faster-whisper** — Speech recognition, excellent Chinese accuracy
- **AutoFlip** — Google, smart landscape-to-portrait conversion
- **react-timeline-editor** — Timeline UI component

### 🎭 6. Digital Humans & Lip Sync

Make photos talk:

- **MuseTalk** — Tencent Music, real-time lip sync, highest offline quality
- **SadTalker** — Single photo + audio → talking video
- **Wav2Lip** — Classic lip sync model, rich community ecosystem

### 🎬 7. AI Drama & Comic Generation

Production-line content generation:

- **BigBanana AI Director** — Industrial-grade, precise character consistency control
- **Toonflow** — Novel-to-video full pipeline
- **LocalMiniDrama** — Fully local deployment, privacy-first
- **ai_story** — Video/anime/drama/comic 4-in-1 automation
- **story-flicks** — Lightest one-click generator
- **ai-shotlive** — Full-pipeline drama generator
- **Komiko** — AI manga/manhwa/anime generation

## My Take

As someone building an AI video editor (QCut), this list covers nearly every project I track daily. Key trends worth noting:

- **Local deployment is now mainstream** — No more API dependency. One 4090 is your render farm.
- **Agentic pipelines are the direction** — ViMax-style LLM-driven director-writer-producer workflows will multiply.
- **Browser editors have matured** — OpenCut and Twick prove that WebCodecs ecosystem is ready for production apps.

If you're building anything video-related, this is a must-bookmark reference.
