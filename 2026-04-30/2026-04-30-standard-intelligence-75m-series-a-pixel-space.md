如果你最近一直在看 Agent 赛道，会发现主流叙事几乎都围着同一套范式打转：

- 更强的语言模型
- 更长的上下文
- 更复杂的 tool calling
- 更精细的 agent harness
- 更会写代码、调 API、点按钮的 computer-use agent

但 Sequoia 合伙人 Sonya Huang 刚刚发的一篇长帖，给出了一个**非常逆潮流、但非常值得重视**的判断：

> 真正通用、真正有用的 computer agent，未必首先来自文本、截图理解和工具调用；它也可能来自**原始视频上的大规模预训练**。

她写的是 **Standard Intelligence** 这家公司刚完成的 **7500 万美元 Series A**。但这篇帖子真正有价值的地方，不是融资数字，而是它把这家公司的**技术赌注、基础设施打法、团队气质和潜在范式变化**讲得很清楚。

一句话总结：

**Standard Intelligence 在赌，训练 Useful Agents 的最优路径不是“让语言模型学会调用工具”，而是“让模型直接从像素流里学会操作电脑”。**

---

## 一、这家公司到底在赌什么？

Sonya Huang 对 Standard Intelligence 的概括非常鲜明：

- 不是让模型预测文本 token
- 而是让模型从**屏幕像素**里直接预测下一步动作
- 包括鼠标移动、点击、键盘输入

也就是说，模型看到的不是“当前网页的结构化状态”或者“工具返回的 JSON”，而是和人类一样，直接看屏幕，然后决定下一步该怎么动手。

这个思路和当前很多 Computer Use / Agent 系统的差异非常大。

今天主流做法更像：

1. 先用 VLM 看懂截图
2. 再让 LLM reasoning
3. 再通过 tool call / browser action / API 去执行
4. 再把结果回灌给模型

而 Standard Intelligence 的思路更接近：

1. 直接看连续视频帧
2. 直接预测动作
3. 让“操作电脑”本身成为一种原生建模对象

Sonya 用了一个特别贴切的比喻：

> **这是把 Tesla FSD 的路线，搬到电脑屏幕上的知识工作里。**

这个比喻为什么重要？因为它揭示了这家公司真正的哲学：

- 不靠大量手写规则
- 不靠越来越复杂的 agent wrapper
- 不靠把语言模型包装成一个层层嵌套的工作流系统
- 而是相信：**只要原始行为数据足够大、预训练足够激进，通用性会从数据里长出来**

这其实是非常“bitter lesson”味道的一条路。

## 二、为什么这是一个真正“反共识”的赌注？

因为视频很难。

而且不是一般的难，是三重难：

1. **算力贵**：视频 token 爆炸，序列很长
2. **存储贵**：大规模原始视频数据极其占空间
3. **工程难**：编码、检索、预训练、动作标注，全都比文本复杂

这也是为什么过去很多“video → AGI”的尝试，最后都半路死掉。

Sonya 在文中专门强调，Standard Intelligence 团队其实并不是“video people”。他们不是那种已经在视频系统里浸泡十年、继承了一堆既有做法的人。相反，他们是从第一性原理重新思考这件事，然后硬生生把一整套基础设施和训练范式搭了出来。

这点很关键。

因为很多真正的新范式，不是从“最懂旧范式的人”那里长出来的，而是从一群愿意怀疑前提的人那里长出来的。

## 三、这篇帖子里最值得注意的四个数字

Sonya 这篇内容里，有四个数字非常值得单独拎出来看。

### 1）1100 万小时的 computer action dataset

这是她给出的第一个重磅信息：

**1100 万小时的电脑操作视频数据集，而且她说这是业内最大。**

为什么这个数字重要？

因为过去 computer-use agent 领域最大的瓶颈之一，就是**动作数据不够大**。

文本有互联网，代码有 GitHub，图片有海量公开图像；但“人类如何长时间操作电脑”的高质量行为数据，历史上一直非常稀缺。

如果 Standard Intelligence 真把这件事规模化了，那它解决的不是一个小优化，而是整个赛道的数据底座问题。

### 2）视频编码器 token 效率高出约 50 倍

帖子里提到，他们做出了一个大约比竞品 **50× 更 token-efficient** 的视频编码器。

效果是什么？

> **将近两小时的 30 FPS 视频，可以塞进 100 万 token 的上下文窗口。**

这几乎就是在说：

- 别人只能看一小会儿
- 他们的模型已经开始能“长时间持续看”

对 computer-use agent 来说，这不是小事。

因为真正复杂的电脑任务往往依赖：

- 长时序状态
- 多轮上下文
- 界面切换
- 反复试错
- 记住几分钟前发生过什么

如果模型只能看几十秒，根本谈不上通用工作流；如果能稳定地看一两个小时，事情的性质就不一样了。

### 3）30 PB 存储集群，成本低于 50 万美元

Sonya 提到，他们在旧金山机架上搭了一个 **30 petabyte** 的存储集群，总成本 **不到 50 万美元**，比 hyperscaler 替代方案便宜大约 **20×**。

这说明什么？

说明这不是一家只会讲“我们有个很酷模型故事”的公司，而是一家愿意把**数据基础设施成本曲线**亲手打下来的公司。

很多 AI 公司最后死得不是模型不行，而是 economics 不成立：

- 数据太贵
- 训练太贵
- 存储太贵
- inference 太贵

如果 Standard Intelligence 连存储成本都在从底层重做，那它在做的就不是一个模型实验，而是一整套可扩展训练体系。

### 4）FDM-1 已经给出早期能力样本

帖子里提到，FDM-1 已经能展示出一些非常有代表性的能力：

- 在 Blender 里挤出一个 CAD 齿轮
- 微调一小时后，在旧金山街区开车
- 像一个好奇的人类一样探索软件状态空间并找 bug

这三件事放在一起看，非常说明问题。

因为它们分别代表了三种完全不同的控制模式：

- **精细 GUI 操作**
- **连续控制 / 时序决策**
- **探索式交互与状态发现**

如果一个统一范式能同时覆盖这三类任务，那它就确实有一点“通用行为模型”的味道了。

## 四、这对 Agent 赛道意味着什么？

我觉得这篇帖子真正值得 builder 深思的地方，不是“这家公司很酷”，而是：

> **它在暗示，Useful Agents 的核心训练对象，也许不该是文本，而该是行为。**

更具体一点：

### 1）今天的 Agent，很多还是“语言模型外接执行器”

当前大量 agent 系统的本质是：

- 大脑是 LLM
- 眼睛是 VLM / screenshot parser
- 手是 tool calls
- 身体是 browser / terminal / API executor

这种方式当然很有效，我们自己每天也都在用。

但它也有明显局限：

- 状态表示往往是离散的、脆弱的
- 环境适配依赖很多手工 glue code
- 操作连续性差
- 长时序动作学习弱
- 工具接口一变，系统就容易碎

### 2）pixel-first 的路径是在赌“操作世界”的统一表征

如果模型原生学的是：

- 看屏幕
- 预测动作
- 承担连续反馈
- 在长视频里维持状态

那它学到的就不是“如何调用某个函数”，而是更接近一种**具身化的数字行为能力**。

这和工具调用式 agent 最大的区别是：

- tool-use 更像“把世界翻译成 API”
- pixel-space pretraining 更像“让模型直接面对世界本身”

对网页、软件、桌面环境、甚至未来更多数字界面来说，后者理论上泛化更强。

### 3）如果这条路成立，很多今天的 Agent 包装层都会被重新定义

这也是为什么 Sonya 说这条路既 contrarian，又 bitter-lesson-pilled。

因为它在质疑一种现在很流行的做法：

> 我们是不是花了太多力气在“给语言模型套越来越复杂的脚手架”，而不是直接扩大它的原始行为训练分布？

如果 Standard Intelligence 这条路真的跑通，那么未来很多今天看起来很重要的东西，都可能变成中间过渡层：

- screenshot + OCR patching
- 手工 action schema
- 大量 heuristic retry logic
- 针对单任务定制的 environment wrapper
- 复杂但脆弱的 tool orchestration

它们不会立刻消失，但地位可能下降。

## 五、Sonya 为什么特别强调团队？

帖子后半段，Sonya 花了很多篇幅写创始人 Galen Mead 和 Devansh Pandey，以及他们整个六人团队。

这不是 VC 式客套，我觉得这里反而透露出一个更重要的信号：

**这家公司卖点不是“已经商业化到哪一步”，而是“这是一群非常早熟、非常认真、愿意长期押注 AGI 路线的人”。**

她强调了几个点：

- 两位创始人都非常年轻（21 和 20）
- 他们在 Atlas Fellowship 时期相识
- 对 AGI 有强烈紧迫感
- 同时对安全问题也很认真
- 整个团队都拒绝了更传统、更体面的路径

这段描述很有 YC / research startup 的味道：

- 小团队
- 大野心
- 强使命感
- 明显反主流
- 技术方向和基础设施路径一起重做

说白了，Sequoia 投的不是一个“现成的大生意”，而是一支可能定义新训练范式的队伍。

## 六、这轮 7500 万美元融资真正买的是什么？

不是品牌，不是新闻热度，而是时间和算力窗口。

如果你相信 Standard Intelligence 的 thesis，那么这轮钱的作用主要有三件事：

### 1）继续扩大数据优势

1100 万小时已经很夸张了，但如果这条路的核心是“规模化动作数据”，那数据飞轮必须继续滚下去。

### 2）继续扩大基础设施优势

30 PB 存储集群只是起点，不是终点。视频优先的预训练路线，本质上就是在和成本、带宽、吞吐量、编码效率打仗。

### 3）争取先手定义新范式

在一个尚未被行业主流承认的方向上，谁先证明：

- video pretraining 可行
- pixel-space action modeling 可扩展
- 通用 computer-use foundation model 能泛化

谁就可能拥有极强的话语权。

所以这轮融资不是简单的“给一家 AGI 公司续命”，而更像是在下注：

> **通用 agent 的预训练范式，可能要从文本中心转向行为中心。**

---

## 七、这篇帖子也有它的“宣传滤镜”

当然，我们也要保持清醒。

Sonya 是投资方，这篇内容天然带有 narrative packaging。里面有很多信息值得重视，但也有几件事还需要继续观察：

1. **这些 benchmark 和 demo 的稳定性如何？**  
   能做一次，不等于能稳定泛化。

2. **pixel-first 路线在开放复杂环境里的 sample efficiency 如何？**  
   直接从像素学动作，通用性强，但训练代价也极高。

3. **这条路线和 LLM-native agent 会是替代关系，还是融合关系？**  
   我个人更倾向后者。

4. **数据质量问题怎么长期解决？**  
   1100 万小时很震撼，但海量视频并不自动等于海量高价值 supervision。

也就是说，现在下结论说“video pretraining 将取代 language-first agents”，还太早。

但说这家公司正在把一个原本边缘的方向，推进成一个不能忽视的研究和创业分支，我觉得完全成立。

---

## 结语

Sonya Huang 这篇关于 Standard Intelligence 的帖子，表面上是一篇融资 announcement，实际上它抛出了一个更大的问题：

> 我们是不是一直在用“文本互联网”的思维，去训练本质上应该活在“行为世界”里的 agent？

如果答案是否定的，那么 Standard Intelligence 的意义就不只是又一家融资成功的 AI 公司。

它代表的是一种新的技术直觉：

- 从文本走向视频
- 从 reasoning wrapper 走向行为预训练
- 从工具调用走向像素空间动作建模
- 从“会说”走向“会做”

这家公司未必已经证明自己是终局答案。

但它很可能已经证明了一件更重要的事：

**Useful agents 的下一次大跃迁，未必发生在更聪明的 prompt engineering 上，而可能发生在更大规模的行为数据和更原生的像素预训练里。**

这，才是这轮 7500 万美元融资最值得关注的地方。
