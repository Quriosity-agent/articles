# GrayNoteLab 唐宋古风人物形象卡提示词拆解：AI 角色一致性的关键，是把审美写成四视图规格

灰度笔记在 X 上发了一条很长的古风女性角色设定图提示词，附了四张 16:9 横版人物形象卡。每张图的结构都很明确：左侧是同一角色的面部与上半身细节，右侧是同一套服装的正面、侧面、背面全身视图。

这条 prompt 表面上是在写“唐宋古风”“宫廷礼服”“超写实摄影”。但真正值得拆的不是这些审美词，而是它把一个经常失控的图像生成任务，改写成了一个角色生产规格：同一张脸、同一套发饰、同一套服装、同一组材质，必须在四个视角里保持一致。

![GrayNoteLab Tang-Song character card sample 1](imgs/graynotelab-tang-song-character-card-prompt/01-character-card.jpg)

## 一句话概括

**这条 prompt 的可复用价值在于：它不是要求模型生成一个漂亮古风女子，而是要求模型交付一张可用于角色设计、服装沟通和后续视频生成的四视图设定卡。**

这和 6 月 17 日那条“破卷而出”视频 prompt 不同。前者解决的是镜头运动里的空间边界问题；这条解决的是角色资产里的身份一致性问题。

## 为什么人物形象卡比单张美图难

单张人像只要一帧好看就行。人物形象卡要同时满足几个更硬的条件：

1. 近景脸部和全身视图要像同一个人；
2. 正面、侧面、背面的发型和头饰不能随视角漂移；
3. 服装结构要能从不同角度解释得通；
4. 透明外衫、宽袖、腰封、拖尾等层级不能在背面消失；
5. 光线和背景要统一，不能像四张不同图拼在一起；
6. 模特比例、头身比、肩宽、腰线高度要保持一致。

这也是很多 AI 角色图最容易翻车的地方。模型很会生成“像设定图的图”，但不一定真的理解设定图的生产用途。它可能给正面换一套衣服、给背面省掉外衫、给侧面换发型，或者让脸部特写和右侧全身图长得不像同一个角色。

灰度笔记这条 prompt 的关键，是把这些失败点提前写进规格里。

## 它其实是一个六层规格表

把源 prompt 抽象出来，可以看到六层结构。

| 层级 | prompt 锁定的内容 | 解决的问题 |
|---|---|---|
| 版式规格 | 16:9 横版，左侧面部特写，右侧三张全身视图 | 让模型知道这不是普通海报，而是角色设定卡 |
| 身份规格 | 亚洲古风女性、年龄感、脸型、五官、肤质、神态 | 让近景和全身视图共享同一人物身份 |
| 发饰规格 | 高位宫廷发髻、凤凰冠、珍珠、花朵、流苏、发链 | 防止视角变化时头饰重组 |
| 服装规格 | 内层长裙、中层束腰、外层半透明薄纱外衫 | 让服装从装饰词变成可追踪结构 |
| 视角规格 | 正面、侧面、背面三张全身图，手臂自然下垂 | 让模型按产品图逻辑展示角色，而不是摆拍 |
| 摄影规格 | 棚拍、暖金布光、85mm 人像镜头、真实材质 | 统一四个视图的质感和光线 |

这比普通“古风美人 prompt”更接近设计交付文件。它不只是描述画面风格，也在定义验收条件。

## 最关键的是“同一套衣服”

源 prompt 反复强调三视图必须是同一人物、同一张脸、同一发型、同一套服装、同一套首饰。这个重复不是啰嗦，而是在对抗生成模型的默认倾向：模型会为了每个视角局部好看，偷偷重写服装。

角色设定图最怕这种“局部合理、整体不一致”。正面看起来华丽，侧面换了腰封，背面没有透明外衫，视频或 3D 建模阶段就无法使用。一个后续创作者不知道应该相信哪一张。

所以这条 prompt 把衣服拆成三层：

- 内层：抹胸式刺绣长裙；
- 中层：多层束腰和腰封；
- 外层：覆盖肩背和手臂的半透明薄纱外衫；
- 下裙：多层落地长裙、刺绣薄纱、轻微拖尾。

这种写法把“华贵宫廷裙”从审美描述变成结构描述。模型即使仍会漂移，也至少收到了更明确的连续性约束。

![GrayNoteLab Tang-Song character card sample 2](imgs/graynotelab-tang-song-character-card-prompt/02-character-card.jpg)

## 背面视图是角色一致性的压力测试

这条 prompt 里最有价值的部分，不是面部特写，而是背面视图。

很多角色设定 prompt 会要求正面和侧面，但背面经常被忽略。问题是，真正进入生产流程之后，背面才是最能暴露服装是否成立的地方：

- 发髻背面是否有结构；
- 凤冠和发链是否能从后方解释；
- 外层薄纱是否真的覆盖肩背；
- 腰封背面和长流苏是否连续；
- 裙身刺绣和拖尾是否和正面属于同一套设计。

灰度笔记的 prompt 对背面写得很细，是因为背面不是附属视角，而是验证设计连续性的关键视角。对 AI 角色生产来说，背面图就是 consistency test。

## 它把负面约束改成了“生产验收”

这条 prompt 里有很多看似普通的避免项：避免大头娃娃感、避免矮小、避免臃肿、避免肩宽、避免腰粗、不要改变服装结构。这些不是通用负面词，而是和角色卡任务绑定的验收标准。

如果把它放进一个可复用工作流，负面约束应该被拆成 checklist：

| 验收项 | 要检查什么 |
|---|---|
| 人物一致性 | 左侧脸部和右侧全身是否像同一个人 |
| 服装一致性 | 正面、侧面、背面的外衫、腰封、裙摆是否连续 |
| 发饰一致性 | 凤冠、珍珠、流苏、发链是否随视角保持逻辑 |
| 比例一致性 | 三个全身视图的身高、头身比、腰线是否接近 |
| 材质一致性 | 透明薄纱、金线刺绣、珍珠和金属是否在不同视图里统一 |
| 版式清晰度 | 是否仍然是一张设定卡，而不是四张风格近似的海报 |

这就是 prompt 从“咒语”变成生产约束的地方。好的角色卡 prompt 不是把形容词写到最长，而是把模型最容易误解的连续性关系写清楚。

## 对 AI 视频和短剧工作流的价值

这类四视图角色卡，真正的用途不止是发图。它可以成为后续视频生成、角色换装、短剧分镜、封面设计和 LoRA / reference image 工作流的上游资产。

如果一个 AI 短剧团队只拿一张正面美图做角色参考，后续会遇到一连串问题：

- 侧脸和背影镜头没有参考；
- 不同镜头的衣服会漂移；
- 发饰、袖型、拖尾在动作中不稳定；
- 镜头越多，角色越不像同一个人；
- 服装和角色资产很难被拆给不同工具复用。

四视图卡的意义，就是先把角色从“一张好看的图”升级成“一个可复用资产”。它不保证模型每次都稳定，但它提供了更强的 reference base。

## 可以产品化成哪些字段

如果把这条 prompt 放进 QCut、AI 短剧工具或角色设定工具，最不应该做的是让用户复制一整段长文本。更好的方式，是把它拆成表单或结构化模板。

| 字段 | 示例 |
|---|---|
| Character identity | 年龄感、脸型、五官、肤色、神态 |
| Layout | 左侧面部特写，右侧正面 / 侧面 / 背面全身 |
| Hair system | 发髻高度、发冠形状、流苏、发链、对称性 |
| Costume layers | 内层裙、中层腰封、外层薄纱、下裙、拖尾 |
| View constraints | 三视图必须同一人物、同一服装、同一首饰 |
| Material palette | 丝缎、欧根纱、透明薄纱、金线刺绣、珍珠、金属 |
| Camera and light | 棚拍、85mm、暖金主光、轮廓光、统一背景 |
| Failure checks | 不换衣、不换脸、不消失外衫、不大头、不臃肿 |

这样一来，创作者可以替换题材：唐宋古风、赛博汉服、民国戏服、机甲少女、游戏 NPC、品牌虚拟人。底层模板不变，变的是身份、服装、材质和世界观。

## 需要注意的边界

这条 prompt 很有参考价值，但也有几个边界：

1. **长 prompt 不等于稳定控制。** 文本越长，模型越可能只抓住高权重词，忽略后面的细节。
2. **四视图不等于真实设计图。** 生成图看起来连续，不代表服装结构真的能被裁剪、建模或拍摄。
3. **古风审美不等于历史复原。** 这里更像唐宋融合的幻想宫廷画册风格，不适合作为严格朝代服饰考据。
4. **角色一致性仍需要工具配合。** 如果要进入视频或系列图，最好再配合 reference image、seed、局部重绘、角色 LoRA 或多图一致性工具。

所以这条 prompt 最适合作为“角色资产规格样本”，而不是一个复制后就能自动解决所有一致性问题的万能文本。

## 可复用公式

从这条案例可以抽出一个通用公式：

```text
生成一张[比例]的角色设定卡；
左侧展示[面部/上半身细节]；
右侧展示同一角色的[正面/侧面/背面]全身视图；
锁定同一[脸型、发型、发饰、服装、首饰]；
把服装拆成[内层/中层/外层/下摆/拖尾]；
明确每个视角必须保留的[结构、材质、比例]；
用负面约束排除[换脸、换装、比例漂移、背面缺结构、材质丢失]。
```

这套公式可以服务很多创作场景。做 AI 视频时，它是角色一致性参考；做短剧时，它是服装和人物资产卡；做游戏或虚拟人时，它是早期视觉设定；做品牌内容时，它能把“风格”变成可检查的视觉规格。

## 结论

GrayNoteLab 这条 prompt 的价值，不在于它写了多少古风形容词，而在于它把审美拆成了角色生产需要的结构：版式、身份、发饰、服装层级、三视图、材质和验收条件。

AI 图像生成越进入生产流程，prompt 就越不像一句灵感描述，越像一份轻量级 spec。能持续复用的不是“超绝美”这样的词，而是让不同视角、不同镜头、不同工具都能围绕同一个角色工作的规格化能力。
