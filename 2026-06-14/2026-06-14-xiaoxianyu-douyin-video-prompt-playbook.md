# 小咸鱼抖音视频提示词拆解：真正可复用的不是金句 Prompt，而是短视频生成的“素材—风格—动作—约束”流水线

这份腾讯文档《[小咸鱼玩AI-抖音视频提示词分享](https://docs.qq.com/doc/DVnF6YmNDZ25XaGNX)》表面上是一组抖音 AI 视频提示词合集：老照片修复、把家人变电影人物、宠物拟人化、游戏开局界面、把自己做成游戏人物、游戏人物集结短片。

但真正值得拆的不是某一句“神级 Prompt”，而是这些提示词背后暴露出来的创作者工作流：**先把素材变成可控参考图，再把参考图转成短视频；先锁定身份、构图和风格，再拆动作、运镜、时间轴和负面约束。**

这类文档很有价值，因为它不是模型厂商的 demo，而是内容创作者在真实平台里反复试出来的“可复制土法”。它把 AI 视频生成从一句抽象愿望，拆成了几个可操作的生产步骤。

## 一句话概括

**这份提示词合集说明：短视频 AI 生成的核心能力，正在从“会写漂亮 Prompt”转向“会设计素材链、风格锚点、动作分镜和失败兜底”。**

换句话说，Prompt 本身只是最后一层文字接口。真正影响结果的，是前面的四件事：

1. **素材锚定**：原照片、三视图、游戏界面图、分身图；
2. **风格模板**：欧美电影、日式暗黑幻想、3A 游戏 UI、西部蒸汽朋克；
3. **动作与运镜**：抬眼、擦血、拔枪、落座、360 度环绕、贴地跟拍；
4. **约束与兜底**：16:9、五官不崩、肢体不扭曲、无闪烁、生成失败就改用分身/涂白脸。

这已经不是单轮 prompt engineering，而是小型的短视频生产 pipeline。

## 文档里的 6 类模板

原文一共整理了 6 个视频方向：

| 期数 | 主题 | 主要方法 |
|---|---|---|
| 第一期 | 老照片修复 | 图生图修复，再直接丢给豆包生视频 |
| 第二期 | 家人变电影人物 | 用 GPT Image 2 类图像模型先做电影风格参考图 |
| 第三期 | 宠物拟人化 | 豆包按目标效果生成，强调“想要什么说什么” |
| 第四期 | 游戏开局界面 demo | 角色设定 → 三视图 → UI 素材图 → 一镜到底视频 |
| 第五期 | 把自己做成游戏人物 | 生活照 → 日常自拍视频 → 暗黑游戏菜单图 → 视频 |
| 第六期 | 游戏人物展示集合短片 | 直接写完整 10 秒 CG 分镜与负面提示词 |

从这张表可以看出，越往后，提示词越不像“描述一个画面”，越像“导演脚本”。尤其第四、第五、第六期，已经开始明确使用素材链、时间轴、镜头语言和负面约束。

## 模板一：老照片修复，本质是“身份保真 + 画质增强”

第一期的核心提示词是老照片 4K/8K 修复：去除划痕、污渍、霉斑、泛黄、褪色、破损，同时 1:1 还原人物五官、发丝纹理、衣物细节、背景环境和真实肤色。

这个模板看似普通，但结构很标准：

```text
任务：老照片 4K 极致高清修复
修复对象：划痕、污渍、霉斑、泛黄、褪色、破损
身份约束：1:1 精准还原人物五官、发丝、衣物、背景
质感目标：真实自然皮肤、毛孔、肤色、色彩饱和度和对比度
保留条件：原构图、透视、光影氛围
负面约束：无过度磨皮、无失真变形
```

这类 Prompt 的关键不是“高清”“8K”这些词，而是**把增强目标和保真约束同时写进去**。只写“修复高清”，模型容易把老人变年轻、把旧照片变成塑料写真；加上“严格保留构图、透视、光影、五官”，才是在告诉模型：增强画质，不要重写身份。

## 模板二：电影人物，不要直接生视频，先做参考图

第二期的做法是：先打开能用 GPT Image 2 类图像模型的网站，把家人照片作为参考图，再输入“欧美电影级别妆造光影、大片、沙漠牛仔、8K 细节、高清”。

这一步很短，但背后的策略很重要：**先用图像模型把人物身份和风格固定下来，再进入视频生成。**

视频模型最怕两件事：

- 角色身份在时间轴中漂移；
- 风格描述太抽象，导致每一帧都在重新解释“电影感”。

先生成一张强风格参考图，相当于给视频模型一个视觉 anchor。它比单纯写“像电影一样”更可控。

## 模板三：宠物拟人化，低门槛但高依赖审美反馈

第三期写得很朴素：“都是豆包生成的，要什么效果说什么词也不难大家可以试试。”

这句话反而说明了一个现实：宠物拟人化这类内容，模型已经足够强，难点不在技术，而在选择方向。例如：

- 是可爱童话风，还是酷炫街头风？
- 是人类职业拟人，还是保留动物特征的半拟人？
- 是静态头像，还是会做动作的短视频？

对创作者来说，这类题材的优势是门槛低、反馈快、容易爆；缺点是同质化很快。所以真正的竞争点会转向“系列化角色设定”和“持续输出的视觉世界观”。

## 模板四：游戏开局界面，是一个完整的素材流水线

第四期最值得看。它不是直接让模型“生成一个游戏开局视频”，而是拆成多步：

1. 先生成角色形象；
2. 用角色图生成三视图；
3. 用三视图生成主菜单界面；
4. 用三视图生成武器展示界面；
5. 用三视图生成服饰自定义界面；
6. 最后把三张图和一段视频提示词丢给豆包，生成“一镜到底”的游戏 UI 动画。

这就是典型的 AI 视频资产链。重点不是 Prompt 多长，而是每一步都在降低下一步的不确定性。

### 为什么三视图重要？

三视图相当于角色设计的“临时设定稿”。它让后续界面图和视频生成有统一的人物身份、服装、比例和装备。没有三视图，模型可能每个镜头都生成一个“差不多但不是同一个人”的角色。

### 为什么要先做 UI 素材图？

因为视频提示词里包含主菜单、装备页、武器详情页、属性数值条、标注线、配件槽、装备组件栏。如果只靠文字直接生成，视频模型很容易把 UI 变成一团不可读的装饰线条。先做几张静态 UI 图，再图生视频，能明显提高一致性。

### 视频提示词的结构

第四期视频提示词包含：

- 角色身份：冷艳年轻女性，代号 NYX-A01/Raven；
- 场景：纯白色高亮虚空背景、极简 3A 科幻动作游戏 UI；
- UI 元素：主菜单、装备页、武器详情页、属性条、部件标注线；
- 动作节奏：0–3 秒起身，3–6 秒拔枪，6–9 秒落座；
- 物理细节：风衣拖拽、头发飞扬、枪口畸变、机械臂反光；
- 画幅：16:9。

这已经接近一个 micro storyboard，而不是普通提示词。

## 模板五：把自己做成游戏人物，关键是“身份锚定 + 分身兜底”

第五期先把生活照转成日常自拍视频，再生成日式暗黑幻想游戏菜单图，最后用这张游戏图生成视频。

这里有一个很实用的结构：

```text
主体锚定：保留五官、发型、眼镜、服装
动作序列：抬眼、擦血、偏头、呼吸、发丝飘动
运镜调度：从隧道远景快速推进，最后定格面部和手枪特写
场景氛围：废弃混凝土隧道、蓝色冷光、潮湿薄雾
风格渲染：日式暗黑幻想游戏菜单、体积光、低饱和、胶片颗粒
约束：五官不崩、肢体不扭曲、无闪烁、无水印、16:9
```

更有意思的是原文的失败兜底：如果豆包生不出来，就用“自己的分身”，把人物脸涂白再生成。

这句话很像创作者经验，而不是官方教程。它说明视频生成仍然有不稳定性：真人身份、血迹、枪械、暗黑风格、动作推进，这些组合可能触发模型安全策略或生成失败。创作者的解决方法不是继续堆词，而是改变输入素材，让模型更容易接受。

这就是实战经验：**Prompt 解决不了所有问题，素材预处理经常更有效。**

## 模板六：角色集结短片，已经是完整分镜脚本

第六期是最完整的 10 秒 CG 动画提示词。它设定了“西部蒸汽朋克 + 暗黑佣兵团 + 工业废土”的风格，并把 10 秒拆成四段角色出场和最后集结：

- 0.0–2.4 秒：左侧女枪手，长风衣、宽檐帽、长步枪；
- 2.4–4.8 秒：兜帽短刃刺客，低身疾冲、双刃、X 形刀光；
- 4.8–7.2 秒：中央重甲领袖，机械臂、重型武器、蒸汽与弹链；
- 7.2–9.6 秒：高瘦绅士枪客，礼帽、面具、手枪、细剑；
- 9.6–10 秒：四人英雄式三角构图集结。

这段提示词最成熟的地方，是它不仅写“每个角色做什么”，还写了**转场机制**：子弹遮蔽转场、X 形刀光转披风边缘、金属碎片遮蔽、剑尖穿透镜头、烟雾进入最终集结。

这对 AI 视频非常重要。很多生成视频看起来像幻灯片，是因为提示词只描述画面，没有描述镜头之间怎么连。这里把转场写进动作本身，让视频模型有机会生成更连续的动势。

## 这份文档背后的可复用公式

把 6 期模板抽象出来，可以得到一个短视频 Prompt 公式：

```text
1. 输入素材：原图 / 参考图 / 三视图 / UI 图 / 分身图
2. 主体锚定：五官、发型、服装、比例、姿势、身份特征
3. 风格方向：电影类型、游戏类型、时代、色调、材质
4. 场景环境：空间、光线、背景、天气、氛围
5. 动作序列：按秒拆分动作，避免只写“动起来”
6. 运镜调度：推拉、环绕、贴地、低角度、俯冲、特写
7. 物理细节：布料、发丝、烟雾、弹壳、火花、惯性
8. UI / 文本元素：如果需要界面，最好先做静态参考图
9. 负面约束：不崩脸、不扭曲、不闪烁、不水印、不低清
10. 失败兜底：换参考图、简化动作、使用分身、拆成多步
```

对创作者来说，最重要的是第 1 和第 10。输入素材决定上限，失败兜底决定能不能稳定产出。

## 对 QCut 的启发：Prompt 应该变成可编辑的 production graph

如果把这份文档放到 QCut 的视角看，它其实在暗示一个产品方向：用户不应该只在一个大文本框里写长 Prompt，而应该在一个可编辑的 production graph 里组织短视频生成。

一个更好的产品形态可能是：

- **素材节点**：上传真人照、宠物照、角色图、三视图；
- **风格节点**：选择电影、3A 游戏、暗黑幻想、蒸汽朋克；
- **图像节点**：先生成角色图、UI 图、海报图；
- **分镜节点**：按 0–3 秒、3–6 秒、6–9 秒拆动作；
- **运镜节点**：推镜、环绕、俯冲、贴地跟拍；
- **约束节点**：身份保真、无变形、无闪烁、16:9；
- **重试节点**：生成失败时自动简化动作或替换参考素材。

这样 Prompt 就不再是一段不可维护的长文本，而是一个可以复用、调参、回滚、分支实验的生产图。

## 对创作者的实际建议

如果要复用这份文档，不建议直接复制全部提示词。更好的用法是：

1. **先复用结构，不要先复用词句**：把“主体锚定 / 场景 / 动作 / 运镜 / 约束”拆出来；
2. **每个视频只解决一个核心难点**：身份保真、动作连续、UI 可读性、风格统一，不要一次全要；
3. **长视频拆成短段生成**：10 秒已经很复杂，必要时拆成 3 个 3 秒段落；
4. **先图后视频**：角色、UI、场景能静态定下来的，先用图像模型定下来；
5. **保留失败样本**：记录哪类词触发失败，哪类参考图更稳定；
6. **把负面约束标准化**：五官、手指、肢体、闪烁、水印、画幅、清晰度应该成为模板字段。

## 我的判断：短视频 Prompt 正在从“文案能力”变成“导演能力”

这份腾讯文档最有意思的地方，是它展示了普通创作者如何自然地走向 pipeline 思维。

早期 AI 绘图时代，很多人追求“神奇关键词”。但 AI 视频的复杂度更高：角色要保持一致，动作要连续，镜头要有逻辑，UI 要可读，时间轴要稳定，失败还要能重试。于是 Prompt 写作不可避免地变成了导演、分镜、制片和技术美术的混合工作。

所以我觉得这份提示词合集真正说明的是：**短视频生成不是靠一条 Prompt 爆发，而是靠可复用的生产流程复利。**

谁能把素材、风格、动作、运镜、约束、重试做成可控系统，谁就会比单纯收藏 Prompt 的人更稳定地产出内容。
