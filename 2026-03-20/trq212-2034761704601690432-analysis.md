## 发生了什么

Anthropic 工程师 Thariq 宣布了 **Claude Code Channels** —— 一个研究预览功能，让你可以通过 Telegram 或 Discord 直接给正在运行的 Claude Code session 发消息。

简单说：**你的手机变成了 Claude Code 的遥控器。**

人不在电脑前？没关系。打开 Telegram，给你的 bot 发条消息，Claude Code 就会收到并执行。CI 跑完了、有个 bug 要修、想 review 一段代码——直接在手机上说就行。

## 工作原理

Channels 本质上是一个 **MCP server**，它把外部消息（Telegram/Discord）推送到你正在运行的 Claude Code session 里。

关键架构点：

- **双向通信**：Claude 读取消息，也通过同一个 channel 回复
- **Plugin 机制**：每个 channel 是一个独立的 plugin，用 Bun 运行
- **安全模型**：配对（pairing）+ 白名单（allowlist），只有你授权的账号才能发消息
- **Session 级别**：channel 只在 session 开启期间活跃——要想一直在线，得把 Claude Code 跑在后台

## 怎么设置

### Telegram 版

```bash
# 1. 在 Telegram 找 @BotFather，创建一个 bot，拿到 token

# 2. 安装 plugin
/plugin install telegram@claude-plugins-official

# 3. 配置 token
/telegram:configure <你的bot token>

# 4. 带 channel 启动 Claude Code
claude --channels plugin:telegram@claude-plugins-official

# 5. 在 Telegram 给 bot 发消息，拿到配对码
/telegram:access pair <配对码>

# 6. 锁定白名单
/telegram:access policy allowlist
```

### Discord 版

流程类似：创建 Discord bot → 开启 Message Content Intent → 邀请到 server → 安装 plugin → 配置 token → 启动 → 配对 → 锁白名单。

详细步骤见：[Discord README](https://github.com/anthropics/claude-plugins-official/blob/main/external_plugins/discord/README.md)

## 为什么这很重要

这不是一个花哨的功能。这是 **Claude Code 从"终端工具"向"全天候 Agent"演进的关键一步**。

想想这些场景：

1. **移动开发者**：出门在外也能指挥 Claude Code 干活
2. **CI/CD 集成**：把 CI 结果推送到 channel，Claude 自动处理
3. **团队协作**：Discord server 里的 bot 就是你的 AI 队友
4. **Always-on Agent**：配合后台进程，Claude Code 变成 24/7 在线的 coding agent

更深层的意义：Anthropic 正在把 Claude Code **从一个 CLI 工具变成一个平台**。Channels 是 MCP 生态的延伸——今天是 Telegram 和 Discord，明天可能是 Slack、Teams、微信……

## 限制和注意事项

- 需要 Claude Code **v2.1.80+**
- 需要 **claude.ai 登录**（不支持 Console 或 API key）
- Team/Enterprise 组织需要**手动开启**
- Session 关闭 = channel 断开（不是持久服务）
- 目前是 **研究预览**，功能会持续扩展

## Builder 的行动建议

1. **试试看**：先用 fakechat（本地 demo）跑一遍流程，理解 channel 的工作方式
2. **Telegram 优先**：如果你只想手机控制，Telegram bot 最简单
3. **考虑后台运行**：`tmux` / `screen` / `nohup` 配合 `--channels` 实现 always-on
4. **自建 channel**：文档提供了 [Channels Reference](https://code.claude.com/docs/en/channels-reference)，你可以为任何平台写自己的 channel plugin
