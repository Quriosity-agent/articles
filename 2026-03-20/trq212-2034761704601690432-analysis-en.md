## What Happened

Anthropic engineer Thariq announced **Claude Code Channels** — a research preview feature that lets you push messages into a running Claude Code session via Telegram or Discord.

The pitch is dead simple: **your phone becomes a remote control for Claude Code.**

Away from your desk? Open Telegram, send a message to your bot, and Claude Code picks it up. CI finished, bug to fix, code to review — just text it from your phone.

## How It Works

Channels are **MCP servers** that push external events (Telegram messages, Discord messages) into your active Claude Code session.

Key architecture details:

- **Bidirectional**: Claude reads the inbound message and replies through the same channel
- **Plugin-based**: Each channel is a standalone plugin running on Bun
- **Security model**: Pairing codes + allowlist policy — only accounts you authorize can send messages
- **Session-scoped**: Channels are only active while the session is open. For always-on, run Claude Code in a background process

## Setup (Telegram)

```bash
# 1. Create a bot via @BotFather on Telegram, grab the token

# 2. Install the plugin
/plugin install telegram@claude-plugins-official

# 3. Configure your token
/telegram:configure <your-bot-token>

# 4. Restart with channels enabled
claude --channels plugin:telegram@claude-plugins-official

# 5. Send any message to your bot on Telegram, get a pairing code
/telegram:access pair <code>

# 6. Lock down to allowlist
/telegram:access policy allowlist
```

Discord follows the same pattern: create bot → enable Message Content Intent → invite to server → install plugin → configure → pair → allowlist. Full steps in the [Discord README](https://github.com/anthropics/claude-plugins-official/blob/main/external_plugins/discord/README.md).

## Why This Matters

This isn't a gimmick. It's a **critical step in Claude Code's evolution from terminal tool to always-on agent**.

Consider these use cases:

1. **Mobile developers**: Direct your Claude Code session while you're away from the keyboard
2. **CI/CD integration**: Push CI results into the channel, let Claude handle them automatically
3. **Team collaboration**: A Discord bot in your server that's also a coding agent
4. **Always-on agent**: Pair with a background process and Claude Code becomes a 24/7 coding assistant

The deeper signal: Anthropic is turning Claude Code **from a CLI tool into a platform**. Channels extend the MCP ecosystem — today it's Telegram and Discord, tomorrow it could be Slack, Teams, or anything with a messaging API.

## Limitations

- Requires Claude Code **v2.1.80+**
- Requires **claude.ai login** (no Console or API key auth)
- Team/Enterprise orgs must **explicitly enable** channels
- Session closes = channel disconnects (not a persistent service)
- Currently a **research preview** — expect expansion

## Builder Action Items

1. **Try it**: Start with fakechat (a localhost demo channel) to understand the flow before connecting a real platform
2. **Telegram first**: Simplest path if you just want phone-to-Claude control
3. **Background process**: Use `tmux` / `screen` / `nohup` with `--channels` for always-on operation
4. **Build your own**: The [Channels Reference](https://code.claude.com/docs/en/channels-reference) docs let you write a channel plugin for any platform
